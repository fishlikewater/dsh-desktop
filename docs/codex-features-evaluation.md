# Codex 功能评估报告（DSH Desktop 壳层可实现性）

> 评估依据：OpenAI Codex 桌面 App 官方文档（[Codex App docs](https://developers.openai.com/codex/app)）与社区教程（[CodexGuide](https://github.com/freestylefly/CodexGuide)）。
> 结论标记：✅ 已有 / 🟡 壳层可实现 / 🔵 需 DSH 服务侧支持 / ⛔ 暂不可行

| Codex 功能 | 说明 | DSH 现状 | 结论 |

| Chat 对话 | 独立对话，互不相干 | DSH GUI 会话体系 | ✅ |

## 三、自动化（定时任务）——重点评估

| Codex 功能 | 说明 | 壳层可实现性 |
|---|---|---|
| 自动化任务 | 指定指令 + 工作树 + **定时间隔**执行 | 🟡 **壳层可做** |

**壳层实施方案**（纯 Rust，无需改 DSH）：
- 内置轻量定时调度器（每日/每周/间隔，仿 cron 语义），配置存本地 JSON
- 触发动作三档：
  1. **通知提醒**（已具备 notification 插件）：到点弹系统通知
  2. **打开会话**：启动 DSH GUI 并定位到指定会话
  3. **发起任务**：🔵 若 DSH 提供"创建会话/发送消息"的 HTTP API，可自动建会话发指令（需调查 DSH 服务端 API，GUI 已见 `api-gateway` 等插件端点，有可行性）
- UI：托盘菜单 + 设置页管理定时任务列表

## 四、归档会话管理 —— 重点评估

| Codex 功能 | 说明 | 壳层可实现性 |
|---|---|---|
| 已归档对话 | 收起不活跃对话，可恢复 | 🟡/🔵 取决于 DSH GUI 是否已支持 |

**方案**：
- 若 DSH GUI 会话树已支持归档：壳层在**托盘菜单/标题栏**加"归档当前会话"快捷入口（🔵 需 DSH 提供 API 或壳层注入 JS）
- 若不支持：归档属会话数据管理，**应优先在 DSH GUI 侧实现**（会话元数据加 archived 标记），壳层无法独立完成

## 九、优先级建议（壳层路线）

**P0（已完成）**：Codex 配色主题、鲸鱼图标、顶部闪烁修复

**P1（已完成第 1 项）**：
1. **定时任务** ✅ 已完成：标题栏齿轮 → 设置面板管理；每天/每周/间隔三种计划；通知/聚焦窗口两种动作；`last_fired` 持久化（重启续跑）；精确睡眠调度（无轮询）；单测 5 例 + 端到端验证通过
2. **主题系统**（多主题 + 强调色 + 字体）🟡 待做
3. **快捷键面板**（查看/自定义/重设）🟡 待做

**P2（中等，部分依赖 DSH）**：
4. **弹出窗口**（无项目独立聊天小窗）
5. **归档会话入口**（托盘/标题栏快捷操作，🔵 需 DSH API 或 GUI 支持）
6. **设置页**（启动行为/外观/自动化集中管理）

**P3（低优先）**：听写、用量面板、动效选项
