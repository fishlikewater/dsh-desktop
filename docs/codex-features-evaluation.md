# Codex 功能对照评估

> 本文档对照 Codex 桌面应用，评估 DSH Desktop（DSH 的 Tauri 桌面壳）的功能位差，作为产品方向判断依据。

## 对照基线

| 维度 | Codex 桌面 | DSH Desktop（v0.1.5） |
|---|---|---|
| 窗口 | 原生无边框 + 自定义标题栏 | Windows 无边框 + 自定义标题栏；macOS 原生窗框 + Overlay 标题栏（VS Code 同款） |
| 背景质感 | 无特别毛玻璃 | Windows 11 Mica / Win10 Acrylic（跟随系统主题） |
| 托盘常驻 | 有 | 有（左键显隐、菜单齐全） |
| 全局快捷键 | 有 | 有（Ctrl+Shift+D 唤起） |
| 开机自启 | 有 | 有（注册表/LaunchAgent） |
| 自动更新 | 有 | 有（tauri-updater + ed25519，双平台 latest.json） |
| 系统通知 | 有 | 有（notify command + 托盘测试项） |
| 文件拖拽 / 图片粘贴 | 有 | 有（drag_and_drop(false) 放行，CDP 验证过） |
| 主题跟随 | 跟随系统 | 跟随 DSH GUI 外观设置（settings.yaml，事件驱动即时同步 + 30s 轮询兜底） |
| 服务自管理 | 内嵌运行时 | 方案 B 纯拉起（Win taskkill /T；mac 进程组 SIGTERM；仅停止本应用拉起的服务） |
| 错误恢复 | 内建 | 覆盖层 + 自适应轮询（10s/2s）+ 15s 加载超时提示 |

## 位差分析

### 已对齐（无差距）

- 托盘常驻、全局快捷键、开机自启、自动更新、系统通知、拖拽粘贴、主题跟随——均已实现且经过验证。

### DSH Desktop 领先

- **macOS 原生体验**：原生红绿灯 + 原生全屏 + Overlay 标题栏（Codex 桌面以 Windows 为主力）。
- **平台自适应细节**：小桌面窗口 clamp、启动无闪烁（visible(false) + 事件驱动显示）、无边框线/无缝隙（DWM 直角 + WS_POPUP + 样式守卫）。

### 差距（Codex 桌面有 / 此处暂无）

| 能力 | Codex 桌面 | DSH Desktop 现状 | 后续方向 |
|---|---|---|---|
| 窗口状态记忆 | 记住大小/位置/最大化 | 每次 1280×840 居中 | 已列入 |
| 窗口贴靠（Win11 Snap） | 系统级 | 无边框窗口丢失系统贴靠 | 已列入 |
| 连接状态可见性 | 标题栏指示 | 覆盖层才有（标题栏无状态点） | 已列入 |
| 首启引导 | 关闭=托盘有引导 | 静默隐藏 | 已列入 |
| 多会话/多窗口 | 多窗口 | 单窗口 | 已列入 |
| 日志查看 | 应用内 | 仅打开目录 | 已列入 |
| 崩溃恢复 | 自动重启 | 覆盖层手动/可选自动 | 已列入 |
| 签名分发 | 已签名 | 未签名（SmartScreen/已损坏告警） | 已列入 |

### 额外差距（Codex 桌面可能没有，但 DSH 场景需要）

| 能力 | 理由 | 后续方向 |
|---|---|---|
| 服务地址可切换 | DSH 服务多实例/端口场景 | 已列入 |
| DPI/显示器热插拔适配 | 多显示器还原不越界 | 已列入 |
| 托盘状态图标 | 服务在线/离线一眼可见 | 已列入 |
| sidecar 可选打包 | 免预装 dsh（方案 B → A） | 已列入 |

## 结论

- v0.1.5 已在窗口质感、托盘、更新、服务管理上对齐 Codex 桌面的主体能力；
- 主要差距集中在**状态可见性、窗口状态记忆、贴靠、首启引导**等桌面日常体验（全部已列入后续优化方向）；
- 分发信任（签名/公证）是发布质量的关键短板（已列入后续优化方向）。

## 评估方法说明

- 对照基于公开产品体验与本文档撰写时的产品认识，非官方对比文档；
- 具体实现差距以仓库内代码为准。
