# Decision Anchor

## 目标（T1.3，来自 docs/development-plan.md）
启动时序去魔法数：消除 Rust 侧 2500/6500ms 居中睡眠线程；窗口居中改为事件驱动（壳页 show 后立即居中）；服务检测初始探测提前确认。

## 验收标准
- [ ] Rust 删除居中睡眠线程（window.rs）；`work_area` command 保留（前端使用）。
- [ ] 前端 `showWindow()` 的居中从固定 120ms 延迟改为 show 完成回调后立即执行（事件驱动）。
- [ ] 5s 强制显示兜底保留（防意外永久隐藏）。
- [ ] 冷启动连续 5 次窗口位置正确（居中、无跳动）。
- [ ] npm run check 全绿；CDP 冒烟通过。

## 范围边界
- 范围内: Rust 居中线程移除、前端居中时序、启动验证。
- 范围外: 服务检测轮询机制（保留 2s）、窗口创建参数、5s 兜底保留。

## 验证命令
- npm run check
- 启动应用 5 次，检查窗口位置（居中）
- CDP 冒烟（主题即时同步）
